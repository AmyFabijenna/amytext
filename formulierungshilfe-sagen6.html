Formulierungshilfen: Nacherzählen von Sagen

2. Klasse NMS

1. EINLEITUNG DER SAGE

Zeit und Ort einführen

  • Vor langer Zeit …
  • In grauer Vorzeit …
  • Vor vielen hundert Jahren …
  • Es war einmal …
  • Damals, als …
  • In alten Zeiten …
  • Zu jener Zeit, als die Menschen noch …
  • Man erzählt sich, dass vor langer Zeit …

Ortsbeschreibungen

  • … in einem abgelegenen Dorf
  • … in den tiefen Wäldern von …
  • … auf einer hohen Burg
  • … am Fuße des Berges …
  • … an den Ufern des …
  • … in der Nähe von …
  • … mitten in den Bergen
  • … in einer kleinen Siedlung

Figuren einführen

  • Es lebte einst ein/eine …
  • Dort wohnte ein/eine …
  • In dieser Gegend hauste …
  • Die Menschen erzählen von einem/einer …
  • Ein tapferer / eine mutige …
  • Ein geheimnisvoller / eine geheimnisvolle …

Spannende Momente beschreiben

  • Ohne Vorwarnung …

  • In diesem Moment …
  • Da erschien / tauchte auf …
  • Zu seinem/ihrem Entsetzen …
  • Mit einem Mal …
  • Unerwartet …

Gefühle und Reaktionen ausdrücken

  • Voller Angst …
  • Mutig / Tapfer …
  • Verzweifelt …
  • Erleichtert …
  • Verwundert / Erstaunt …
  • Entsetzt / Verängstigt …
  • Hoffnungsvoll …

6. SCHLUSS DER SAGE

Auflösung des Geschehens

  • Und so geschah es, dass …
  • Von diesem Tag an …
  • Seitdem / Seither …
  • Aus diesem Grund …
  • Daher kommt es, dass …
  • So erklärt sich …
  • Bis zum heutigen Tag …

Lehren und Botschaften

  • Diese Geschichte lehrt uns …
  • Die Menschen sollten daraus lernen …
  • Als Warnung für alle …
  • Zum Zeichen dafür …
  • Die Sage mahnt uns …
  • Man sagt, dass …

Bezug zur Gegenwart

  • Noch heute kann man …
  • Die Einheimischen erzählen sich …
  • Bis in unsere Zeit …
  • Wer aufmerksam ist, kann noch immer …
  • An diesem Ort erinnert … daran
  • Die Spuren sind noch sichtbar …

  • Die Legende besagt …
  • Man sagt sich …

Zweifel und Glauben ausdrücken

  • Es soll geschehen sein …
  • Niemand weiß genau, ob …
  • Die einen glauben, die anderen nicht …

  • Ob es sich wirklich so zugetragen hat …

8. ÜBERGÄNGE UND VERBINDUNGEN

Begründungen

  • Weil / Da …
  • Deshalb / Deswegen / Darum …
  • Aus diesem Grund …
  • Daher …
  • Denn …
  • Aufgrund von …

Gegensätze

  • Doch / Aber / Jedoch …
  • Allerdings / Dennoch …
  • Obwohl / Obgleich …
  • Trotzdem / Trotz allem …
  • Im Gegensatz dazu …
  • Andererseits …

Ergänzungen

  • Außerdem / Zudem / Überdies …
  • Auch / Ebenso …
  • Darüber hinaus …
  • Hinzu kommt …
  • Nicht nur … sondern auch …

9. TIPPS FÜR EINE GELUNGENE NACHERZÄHLUNG

Zeitform

✓ Verwende das Präteritum (Vergangenheit) als Hauptzeitform
✓ Beispiel: “Der Ritter ritt durch den Wald und sah plötzlich …”

Reihenfolge

✓ Halte dich an die chronologische Reihenfolge
✓ Verwende Zeitangaben und Bindewörter

Sprache

✓ Benutze abwechslungsreiche Verben statt immer “gehen”, “sagen”, “sein”
✓ Baue Adjektive ein für lebendige Beschreibungen
✓ Vermeide zu viele Wiederholungen

Länge

✓ Konzentriere dich auf das Wesentliche
✓ Nebensächliches kann weggelassen werden
✓ Der Höhepunkt sollte ausführlicher erzählt werden

Atmosphäre

✓ Erzeuge Spannung durch passende Beschreibungen
✓ Nutze sagentypische Formulierungen
✓ Achte auf eine geheimnisvolle, märchenhafte Stimmung
